# Contributing

Thank you for helping improve this NLUO website redesign concept.

## Before opening a pull request

1. Create a feature branch from `main`.
2. Keep changes focused and explain the reason for them.
3. Do not commit credentials, `.env` files, private student information, or unpublished University material.
4. Use official, verified University information and record the source when adding factual content.
5. Preserve accessibility, responsive behaviour, and `prefers-reduced-motion` support.
6. Run the checks listed below before submitting a pull request.

## Local checks

```bash
npm ci
npm run lint
npm run typecheck
npm run db:validate
npm run build
```

## Brand and content

This is an independent redesign concept, not an official University publication. Use official logos, video, photographs, marks, and institutional content only when authorised. Do not publish the prototype as the University's official website without written approval.
